## 136.“和”、“而”与“并”

(1) 长江和黄河是中国最大的两条河。 

(2) 他和我都去了。 

(3) 长而空的文章没人想看。 

(4) 战士们机智而勇敢,很好地完成了任务。 

(5) 代表们讨论并通过了这个决议。 

(6) 我们已经搜集并整理了这些资料。 

(7) 游泳和滑冰都是很有意思的运动。 

(8) 他喜欢干净和整洁。 

## 疑问

连词“和”、“而”、“并”都能连接词和词组，它们在用法上有什么不同？ 

## 析疑

一般来说,连词“和”、“而”、“并”所能连接的词或词组的类别是不同的,请看下表: 

名词/代词 + 和 + 名词/代词 

报纸和杂志 

$$
\text { 形容词 } \quad + \text { 而 } + \text { 形容词 } \quad \text { 温柔而美丽 }
$$

动词 + 并 + 动词 继承并发扬 

需要注意的是： 

1. 用“并”连接的动词，往往是有递进关系，或时间上的先后关系，如例(5)、(6)。 

2. 如果是两个或两个以上的动词或形容词并列在一起作主语或宾语时，中间要用“和”来连接，而不用“并”或“而”。如例(7)： 

$$
\left. \begin{array}{l} {\text {形} + \text {和} + \text {形(主语)}} \\ {\text {动} + \text {和} + \text {动(主语)}} \end{array} \right\} \quad + \text {谓语} + \text {宾语}
$$

例(8): 

$$
\text {主语} + \text {谓语} + \left\{ \begin{array}{l l} \text {形} + \text {和} + \text {形(宾语)} \\ \text {动} + \text {和} + \text {动(宾语)} \end{array} \right.
$$
