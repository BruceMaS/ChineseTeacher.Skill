## 3. 本次减重：原文层 11 份 → 4 份（2.28 MB，余量 736 KB）

平台报「解压后 3,338,123 字节 > 3,145,728」。当时解压实测 4.08 MB，其中 `kb-raw/` 占 2.53 MB。

**判断标准不是"重要不重要"，而是"这本书有没有被分片覆盖"**：

| 书 | 原体积 | 处理 | 依据 |
|---|---|---|---|
| 语法手册 1、2 | 603 KB | **移除原文** | 63 个分片 = 全书的 1:1 切分（切片 139,529 字 vs 原文 137,263 字，差额是分片头） |
| 释疑 201 例 1、2 | 378 KB | **移除原文** | 201 个分片 = 全书 1:1 切分（95,104 vs 89,225 字） |
| 课堂技巧手册 | 114 KB | **移除原文** | 42 个分片 = 全书 1:1 切分（34,474 vs 32,619 字） |
| 等级标准 1、2 | 832 KB | **移除原文，改抽表** | 主体是词汇表（545 KB）与汉字表（90 KB）；已转为 5 张 TSV |
| 面试指南 | 269 KB | **保留** | 无分片，说课案例与问答范例正文只在这里 |
| 跨文化交际学概论 | 357 KB | **保留** | 无分片，各章论述只在原文 |
| 汉语拼音正词法 | 29 KB | **保留** | 无分片，国标条文与示例（国家标准的引用有正当性） |
| 语法点汇总 | 13 KB | **保留** | 无分片，40 项清单 |

**净减 1.79 MB，能力不降反升**——为了删等级标准原文，先补了两张原本只存在于原文里的表：

- `kb-index/syllables.tsv`：音节分级 1097 条（一至七九级）
- `kb-index/handwriting.tsv`：手写汉字 1200 条（初等 300 / 中等 400 / 高等 500，与国标完全一致）

### 顺带修掉的一个会答错问题的缺陷

`char-levels.tsv` 原来只有 1、2、3、7-9 级。原因是 **5.4/5.5/5.6 三个小标题在 OCR 中丢失**，抽"三级汉字表"时一路吃到 5.7，把四、五、六级的 1084 个字全部标成"三级"——**超纲判定会直接判错**。

后重新解析该书第 24—27 页，补齐了三个小标题与对应字表，现已拆成三、四、五、六级四张独立表（300 / 235 / 300 / 250 字）。再补四级第 1—65 字、六级第 1—50 字两处缺页截图后，四级、六级各自补齐到 300 字，**一至六级全部为编号 1—300 连续无缺的完整表**，超纲判定不再有"查不到"的死角。

### 为未来增量预留的空间

余量 736 KB（24%）。按现有体量估算，还能再放：一本 300 KB 的教材原文，或 2000 条分级词表，或 8 张能力卡。
若要放更多，`--no-raw` 模式可再降到 **1.63 MB**（余量 1404 KB），代价是那 4 种书的正文不可读。

### 为什么删原文不会让 agent "找不到东西"

- 分片头已加注「原书未随包，本片即该单元原文」，避免 agent 去开不存在的文件；
- `SKILL.md` 检索协议第 3 条改为：**只有那 4 种可回退原文**，其余改用 `grep -rl '关键词' kb-grammar/` 定位分片；
- `postbuild.py` 硬门禁拦下 1 处漏改的引用（`grammar-levels.md` 原指向已被删的等级标准）。

## 4. 重建命令

```bash
cd books/hanyu-teacher-lesson-prep
python scripts/build_kb.py          # 重建知识库（raw 只复制 4 种，见 CORE_RAW）
python scripts/postbuild.py         # 编译 + 扁平化 + 重写引用 + 硬门禁
cp -r ../../dist/hanyu-teacher-lesson-prep ~/.workbuddy/skills/   # 装本地
python scripts/pack_market.py --author "Bruce" --version 1.0.1 \
    --desc-zh "本技能由多本国际中文教育工具书蒸馏而成，主要为汉语教师提供备课思路。"
```

三脚本各带断言：源结构一变就报错停下，不静默产出坏包。
`pack_market.py` 现在**按解压后字节数**判定体积（上次就是只看了压缩包 1.52 MB 才漏过）；想进一步瘦身加 `--no-raw`，体积降到 1.63 MB。

## 5. 后台提交（剩下的人工步骤）

1. 打开 <https://open.workbuddy.cn/>，登录（未入驻先完成个人/企业认证）。
2. 左侧「技能」→「创建 / 发布技能」。
3. **配置技能**：拖入 `dist/market/hanyu-teacher-lesson-prep.zip`，等待解析生成技能 ID。
4. **确认信息**：填标题、**分类（建议：教育学习 / 办公协同）**、标签（汉语教学、备课、国际中文教育、等级标准）、使用说明。
   - 简介已写进 frontmatter，后台若需再填，用同一段。
   - 使用说明建议加两句：① 适合国际中文教师与证书考生；② 不含语音本体与汉字本体知识，这类问题会明确标注来源。
5. **提交审核** → 等结果 → **审核通过后再点发布**（两个状态，别漏）。
6. 若仍解析失败：把平台报的原文发我，我按它的规则再调。

权限面（写进详情页能提高过审率）：本技能只读包内文件，不联网、不写外部、不执行脚本。

## 7. 上架前必须你自己拍板的一件事：版权

现在包里**含 4 种出版物的全文副本**（面试指南、跨文化交际学概论、汉语拼音正词法、语法点汇总，约 652 KB）。

- 比上一版（8 种、11 个文件）**明显改善**：教材类的整本复制已经没有了，剩下的是 3 种"没有分片就只能整本带"的书 + 1 部国家标准。
- 但仍不等于解决授权：63 个教学单元的结构、201 条辨析的析疑逻辑、42 个课堂问题的处置方案，本身也属实质性使用。

三个选项：

| 选项 | 做法 | 风险 |
|---|---|---|
| **A. 只自用 / 内部教研** | 不上市，用本地版（已装好，功能完整） | 最低，无需处理授权 |
| **B. 免费上架 + 去原文层** | `pack_market.py ... --no-raw` 重新打包（1.63 MB） | 中等：仍可能被投诉，但可主张"摘编" |
| **C. 上架 + 保留原文层** | 现状 2.28 MB，功能最完整 | 较高：4 种原文仍在，建议先取得授权 |

我的建议：**只自用就选 A**，什么都不用改。想公开就选 B——语法、辨析、课堂、等级对标四块能力完全不受影响（它们靠分片，不靠原文层），损失的只是说课案例、跨文化论述、拼音条款示例三块的正文。选 C 请先联系出版社谈授权，别抱着"被投诉就下架"的心态提交。
