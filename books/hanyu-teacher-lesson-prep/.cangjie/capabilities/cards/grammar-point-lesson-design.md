# 语法点五段式备课

## R — 原文

> 知识扫描：以外国学生为教学对象，用简洁的语言解释语法概念。· 格式：用格式化的方式展示语法结构是本书的主要特点之一。· 常见偏误：这些是外国学生在学习过程中出现的真实偏误。· 教学提示：指出教师在讲解和操练该语法项目的过程中需要注意的问题。· 教学建议：模拟真实课堂，为教师提供多种课堂教学解决方案。每个语法项目都至少提供两种教学案例，教师可以根据教学需求灵活地选用。
>
> ——《国际汉语教师语法教学手册1》第 46–52 行（凡例）

## I — 自述

这五段不是五个可以任选的栏目，而是一条**从语言知识降到课堂行为**的降维链：

1. **知识扫描**把语法书的定义翻译成外国学生听得懂的话（不提"状语"这种术语也能讲清）。
2. **格式**把规则压成带槽位的结构式，让"学生该往哪里放什么"变成看得见的位置问题。
3. **常见偏误**用真实错句提前暴露这些槽位的风险点。
4. **教学提示**把偏误归纳成讲解时必须踩准的雷区。
5. **教学建议**给出可以直接照读的课堂话语（师问生答的完整脚本）。

关键在于顺序不是随意排的：**第 3 段决定第 2 段要强调哪个槽位**。以"也"为例，偏误是"也"跑到了主语前面、动词被省掉，所以格式段必须把"也+V"和"也"的位置单独列出来；如果顺序倒过来先讲格式再讲偏误，教师就不知道该在格式里重点圈哪一处。

只做第 1 段，学生听得懂但不会用；只做第 3 段，课上成纠错课。备课的成品不是一段解释，而是这五段连起来的一份可执行脚本。

## A1 — 书中案例（副词"也"）

- **问题**：初级班要教"也"，教师容易只讲"表示相同"，学生造出"也我妹妹喜欢唱歌"。
- **怎么用**：先读知识扫描（"也"表示两事相同、作状语、位于动词形容词之前）→ 格式列四种槽位（Sub₁+V，Sub₂+也+V 等）→ 偏误段给出两条真实错句：①"也"误置于主语之前 ②"也"后面的动词遗漏 → 教学提示因此归纳为"只能放在动词形容词之前"和"'也'总在'都'前面"。
- **结论**：偏误段直接生成了教学提示的两条雷区；教学建议的"案例1 图片法"用赫本照片教"主语相同"的情形，"案例2"教"主语不同"的情形，恰好对应格式段的两类槽位。
- **结果**：五段之间是**互锁**的——任何一段被跳过，另外四段都会失去依据。

## A2 — 触发场景（何时用）

用户会这样说：

- "我要讲'了'/'把'字句/'趋向补语'，怎么备课？"
- "这个语法点怎么导入？帮我写这节课的教案。"
- "学生老是说成 X，我应该怎么讲？"
- "初级班讲'比'字句，讲到什么程度？"
- "帮我设计一节课，45 分钟，教'越来越'。"

**与相邻能力的区分**：

- 只问"X 和 Y 有什么区别"→ 用《易混点辨析》，不用本卡。
- 只问课堂纪律、学生不开口、教材选择 → 用《课堂问题诊断》。
- 只问"这个点在几级"→ 用《等级对标与超纲控制》。

## E — 执行步骤

1. **定位语法点**：读 [语法点分片索引](../kb/index/grammar-points.md)，按名称或关键词找到检索码。找不到 → 进第 7 步。
2. **读一个分片**：`../kb/grammar/<检索码>.md`。只读一个，不要连读多个点。
3. **定等级与边界**：在 [国标语法等级索引](../kb/index/grammar-levels.md) 查该点的等级；用 `../kb/index/vocab-levels.tsv` 与 `char-levels.tsv` 检查拟用例句里的词、字是否超纲。等级必须来自索引，**不得凭感觉判断**。
4. **改写知识扫描**：把手册的表述改成面向该班学生母语背景的说法；若明知某母语会迁移出特定错误，补一句对比说明并标注"补充，非本库"。
5. **按五段式重排教案**：导入 → 格式呈现 → 偏误预警 → 讲解雷区 → 操练与活动 → 板书 → 作业。每步都要能指回第 2 步读到的具体段落。
6. **输出**：一份可直接上课的教案 + 一段可照读的师生话语脚本（这套语料的独特价值就在这段，不要写成教学目标的罗列）。
7. **判停**：若第 1 步找不到分片，或第 3 步等级无法确定 → 先明确告知"本库无该点真实偏误/等级待核"，再给方案，并标注哪些内容来自模型推测。

**完成标准**：教案里每个环节都能被追溯到五段中的某一段或 KB 中某条具体条目；没有一句"根据学生情况灵活处理"这样的空话。

## B — 边界

- **不是所有语言点都走五段式**。词汇、课文、文化专题没有"格式"段，应改用《操练梯度与课堂活动》+ 课堂技巧库。
- **等级差超过两级不要硬教**。学生是二级水平却要讲"把"字句的篇章功能，正确做法是换点或降维，而不是把高级内容简化后硬塞。
- **手册未覆盖的点不得编造偏误**。62 个分片之外的语言点（如"所"字结构、文言虚词），本库没有真实偏误数据；可以给教学方案，但必须标注"偏误为推测"。
- **不要用本卡回答"这词什么意思"**。那属于辨析卡或直接问答。
