# 说课与试讲

## R — 原文

> 说课要点有四：教学对象、教学目标和教学内容、教学重点和难点、教学步骤。
>
> ——《〈国际汉语教师证书〉面试指南》第四节（第 246 行）

> 说课时设计的教学目标只是上述小目标里的一课或一课中的部分内容, 所以要根据所给内容以一节课的目标来设计。……说课注意事项：要突出教学设计思路和理论依据，不要平铺直叙复述教案。
>
> ——同书第四节（第 286、221 行）

## I — 自述

说课和试讲是两件不同的事，混起来就两头落空：

- **说课回答"为什么这么设计"**。它不是把教案念一遍，而是把设计背后的取舍讲出来：为什么这个点是重点、为什么先讲 A 后讲 B、为什么用图片而不是翻译。
- **试讲回答"具体怎么做"**。它直接进入师生互动，用教师的原话、板书、领读、追问把课堂演出来，**不能退回陈述语气再说一次说课**。

说课的四要点有固定颗粒度，容易讲错的地方恰恰在颗粒度上：

| 要点 | 该讲到什么程度 | 常见错误 |
|---|---|---|
| 教学对象 | 年龄段 + 汉语水平（两者缺一不可） | 只说"初级班"，不说年龄 |
| 教学目标与内容 | 只定**一节课**的小目标，分词汇/句型/语法/课文/文化/练习 | 把一学期的大目标搬上来 |
| 重点与难点 | 各一条，且难点要说明"难在哪" | 重点难点写成同一句 |
| 教学步骤 | 只讲大框架 + 课时分配，不必细到每句话 | 把试讲内容提前讲完 |

试讲则是这套语料里最稀缺的资源：它要求教师**预判学生的真实反应**（说错、说不出、跑题、提问），并准备好应对。手册里那些带师问生答的教学案例，就是最好的试讲脚本范本。

## A1 — 书中案例（说课的颗粒度）

- **问题**：考生把说课讲成教案朗读，3 分钟讲不完，且听不出设计思路。
- **怎么用**：按四要点重排——教学对象明确"16–18 岁高中生、二级水平"；教学目标限定为本课时的一个小目标；重点难点各一条；教学步骤只给"导入（5'）→ 呈现（10'）→ 操练（15'）→ 活动（10'）→ 小结（5'）"的框架。
- **结论**：书中明确"说课部分的教学步骤不需要太具体，只需指出教学步骤的大框架即可"，并要求先说明本课需几个课时、每课时多少分钟，再讲所选课时的步骤。
- **结果**：说课从"复述教案"变成"解释设计"，时间也压得住。

## A2 — 触发场景（何时用）

用户会这样说：

- "我要考国际中文教师证书，帮我准备说课/试讲。"
- "明天公开课，帮我说课稿。"
- "说课稿怎么写？几分钟讲多少字？"
- "试讲时没有学生配合，怎么演？"
- "评委问我为什么这样设计，怎么答？"

**与相邻能力的区分**：本卡专用于**面向评委/同行的展示性教学**（面试、公开课、教研）。日常备课 → 《语法点五段式备课》；课堂真实困境 → 《课堂问题诊断》。

## E — 执行步骤

1. **确认场景与时长**：面试（说课 3 分钟 + 试讲 7 分钟）／公开课／教研说课。时长决定详略，先问清。
2. **定四要点**：按上表逐项写，教学对象必须"年龄段 + 水平"两项齐全；目标只写一课时。
3. **写说课稿**：3 分钟约 600–700 字，结构为"对象 → 目标与内容 → 重点难点 → 步骤框架 → 设计依据"。每讲一个设计选择，后面跟一句"因为……"。
4. **选点做试讲**：从说课内容里挑 1–2 个教学点（不要多），按"导入 → 讲解 → 操练 → 活动"写**师生对话脚本**，包含学生可能的错误回答与教师应对。
5. **备问答**：按 [面试指南索引](../kb/index/interview.md) 的案例分析两步法准备——有既有结果用"关键问题→处理方案→合理建议→行动方案"，无结果用"分析原因→解决方案→利弊评析"。
6. **自查**：说课里有没有出现"然后我让学生……"这种流水账？试讲里有没有退回陈述语气？两个问题任一为"是"，重写。
7. **判停**：若用户只要试讲不要说课，跳过第 3 步，但第 2 步的四要点仍要写，因为试讲选点依赖重点难点。

**完成标准**：说课稿能被计时朗读且不超时；试讲脚本里学生至少"说错"一次并被妥善处理；四要点无一项缺失或错位。

## B — 边界

- **不要用应试逻辑污染真实备课**。说课的"3 分钟框架"是为了展示，不等于课堂上真该这么切分时间。
- **试讲不要虚构学生**。没有学生时也要写出"预设学生反应"，而不是自问自答式地念台词。
- **不要把所有语法点都塞进一节课**。重点难点各一条，多于此说明没做取舍。
- **外语问答题**（面试第四部分）本库只有英文范式，非英语语种的应答需靠模型自身能力，应如实说明。
- **本卡不负责具体语法点的讲解内容**，那要回到《语法点五段式备课》查分片。
