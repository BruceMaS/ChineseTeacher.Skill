# 操练梯度与课堂活动

## R — 原文

> 课堂活动一定要与语言知识的教学紧密结合。……活动一定要有较强的互动性、趣味性与实效性。实效性是指该活动可以成功地帮助学生实现从语言知识向言语技能的转化。
>
> 设计课堂活动还有一些禁忌，如活动程序过于复杂、只玩不学、不能保证学生参与的公平性、可操作性不强、道具准备复杂、解释语言繁琐。
>
> ——《国际汉语教师课堂技巧手册》第 26 问

## I — 自述

操练不是"多做练习题"，而是一条**控制度递减的四级阶梯**：

1. **机械操练**：只求形式正确，不承载真实信息（替换、扩展、认读）。
2. **有意义操练**：形式 + 意思，学生要理解才能答（看图说话、判断对错、猜谜）。
3. **半交际**：存在信息差，答案不唯一但仍有目标结构（问卷、找同伴、采访）。
4. **交际任务**：有真实目的和结果（办事、协商、解决问题），结构退居其次。

每一级只解决一个问题：机械解决"说得对"，有意义解决"知道什么意思"，半交际解决"能想起来用"，交际解决"用得得体"。**跳级的典型症状是"会做题、不会说话"**——学生能填空，一开口还是不用这个结构。

这套语料里"操练"小节常直接标出类型（认读练习 / 看图说话 / 交际练习），那正是梯度的落地写法；备课时应当照着补全缺的层级，而不是把书上的活动照搬一遍。

活动设计另有六条硬禁忌（程序复杂、只玩不学、参与不公、不好操作、道具复杂、解释繁琐）。它们的作用是**否决**，不是建议——任何一条踩中，活动就该重做。

## A1 — 书中案例（课堂活动的四条原则）

- **问题**：年轻教师热心组织活动，但学生不配合、或活动热闹一场什么也没学到。
- **怎么用**：按四条原则自查——①花样翻新（不千篇一律）②有质有量（一节课一两个活动，时间和数量都要控制）③与语言知识紧密结合 ④互动性、趣味性、实效性。再用六条禁忌逐条否决。
- **结论**：书中以"抢拍词语"游戏为例说明好活动为什么好：道具简单、规则一句话说清、人人可参与、直接服务于词汇提取——正好对应"可操作性强"和"实效性"。
- **结果**：活动设计的判断标准从"有趣吗"变成"它把学生从哪一级推向哪一级"。

## A2 — 触发场景（何时用）

用户会这样说：

- "这个语法点怎么操练？"
- "帮我设计几个课堂活动。"
- "学生上课没兴趣，活动怎么搞？"
- "练习环节总是很闷，怎么办？"
- "这节课 45 分钟，讲完还剩 20 分钟做什么？"

**与相邻能力的区分**：本卡负责"练什么、按什么顺序练、活动怎么设计"。讲解怎么讲 → 《语法点五段式备课》；学生出错怎么纠 → 《偏误预测与纠错决策》；活动组织不起来、纪律乱 → 《课堂问题诊断》。

## E — 执行步骤

1. **锁定目标结构**：确认本课要练的那一个形式（一次只练一个，混练是常见失误）。
2. **读原书操练段**：打开对应分片 `../kb/grammar/<检索码>.md`，找"操练""课堂活动""训练营"小节，看原书用了哪几级、缺哪几级。索引见 [语法点分片索引](../kb/index/grammar-points.md)。
3. **补齐梯度**：至少给出机械、有意义、半交际三级；课时允许再加交际任务。每级 1 个活动，宁少勿多（书里明确"一节课一两个活动"）。
4. **写清三件事**：活动指令语（教师原话）、预计时长、教师在这一步观察什么（即纠错触发点）。
5. **六禁忌自查**：程序复杂 / 只玩不学 / 参与不公 / 不好操作 / 道具复杂 / 解释繁琐——命中任何一条就重做。
6. **判停**：若目标结构在库里没有分片（生词、课文、文化专题），跳过第 2 步，直接按梯度设计，并说明"无原书操练参考"。

**完成标准**：每个活动都能说出"它把学生从第几级推到第几级"；指令语能被教师照读；六禁忌逐条过一遍且无命中。

## B — 边界

- **不要用活动替代讲解**。学生不知道形式是什么，活动只会放大错误。
- **活动数量不是质量**。一节课堆四个活动，每个都浅，不如两个练透。
- **不要设计需要大量道具或长指令的活动**，尤其在海外课时少、班额大的场景。
- **参与公平性**：抢答类活动会让强势学生垄断，必须配点名或轮换机制（见课堂技巧库第 46 问"学生总喜欢抢答"）。
- **本卡不解决"学生根本不愿开口"**。那是动机与心理问题，转《课堂问题诊断》。
