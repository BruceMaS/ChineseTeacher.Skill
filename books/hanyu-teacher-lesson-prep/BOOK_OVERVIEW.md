# BOOK_OVERVIEW — 汉语教师备课知识库

> 这不是"一本书"，而是 9 份对外汉语教学工具书的合集。因此阶段 0 的 Adler 四步被改造为：
> **来源分工 → 骨架 → 术语 → 批判**。四步的目标不变：给出一个能被后续 extractor 复用的全局骨架。

## 二、骨架：备课的四层结构

语料表面散乱，但所有来源都指向同一个四层结构。这是本知识库的**主骨架**，也是能力卡的划分依据：

```
第四层  文化层   为什么这个说法"不得体"/为什么这个课堂冲突会发生
                 ← 跨文化交际学概论、课堂技巧（文化教学）
第三层  实施层   怎么在 45 分钟里把它教出去、学生出错时怎么办
                 ← 课堂技巧手册、语法手册的"教学建议"与"课堂活动"
第二层  设计层   这节课教什么、重点难点是什么、步骤怎么排、怎么操练
                 ← 面试指南（说课四要点）、语法手册的五段式、训练营
第一层  知识层  这个语法点到底是什么、格式怎么写、学生会错在哪
                 ← 语法手册（知识扫描/格式/偏误）、释疑 201 例、拼音正词法
```

**关键洞察**：这套语料的价值不在于"知识条目多"，而在于**它把一句话语法知识一路推到了可执行的课堂脚本**——「知识扫描」给教师能听懂的解释，「格式」给可视化结构，「常见偏误」提前暴露学生真实会犯的错，「教学提示」标出讲解雷区，「教学建议」直接给出带师生对话的完整教学案例。绝大多数语法参考书停在第二段，这套书把后三段补齐了。这四段之间的顺序本身就是方法论。

## 四、批判（这套语料不能解决的问题）

按 Adler 的批判阶段，逐条列出：这些材料本身有什么盲区，skill 必须诚实承认而不是硬编。

1. **语音本体知识几乎为零**。全部语料中"声调/变调/儿化/轻声"只在拼音正词法（书写层面）和课堂技巧手册的"语音教学有哪些好方法"一节出现。**没有**声韵母系统、连读变调规则、儿化音变的系统讲解。→ skill 在语音教学上只能给方法，本体知识必须标注"来自模型自身知识，非本库"。
2. **汉字本体知识同样缺失**。只有"汉字练习的技巧""学生依赖拼音怎么办"两条方法论，没有笔画、部件、造字法的系统内容。→ 同上。
3. **偏误没有国别标注**。语法手册的偏误是"真实偏误"，但没说是哪国学生的。而母语迁移恰恰决定偏误预测的准确度。→ skill 必须要求 agent 先问学生母语，再用模型自身知识补迁移分析，不能假装库里写了。
4. **OCR 损伤**。语法手册 2 与释疑 201 例 2 有多处识别错误（"常见偏程"=常见偏误、"倒"与"但"其实是"倒"与"却"一类），释疑 201 例缺 9 个条目标题。→ 引用时必须核对语境，不能只信标题。
5. **跨文化部分是 20 世纪教材**。框架经典（Hofstede 式价值观维度、非语言交际），但案例陈旧，对当代课堂（穆斯林学生、非洲学生、LGBTQ 议题、线上教学）覆盖不足。→ skill 把它的价值定位为"术语与框架校准"，具体应对靠模型。
6. **面试指南是应试导向**。说课四要点本质是"15 分钟面试怎么讲"，不完全等于真实备课。→ 只在"说课/试讲/公开课"场景启用，不污染日常备课流程。

## 六、应用场景（决定 A2 怎么写）

1. 教师要上一节新课，手里有一个语法点，要产出可上课的教案与话语脚本。
2. 学生问"X 和 Y 有什么区别"，教师要能当场给出可检验的解释。
3. 教师要预测这班学生会在哪出错，并提前准备应对。
4. 教师要参加说课/试讲/公开课。
5. 教师要给出词语、专名、句子的规范拼音。
6. 课堂上出了状况（不开口、抢答、依赖拼音、文化冲突），教师要当场决策。
